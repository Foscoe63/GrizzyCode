Agents

An agent is a runtime profile, not just a prompt: its own instructions, model and reasoning effort, the tools and folders it may touch, a step budget, rules on individual tool calls, and completion checks GrizzyCode runs against what it actually did before it may finish. Pick one from the composer, or let the model delegate to it. Built-in agents can be edited and reset; Grizzy is the Claude Code CLI and is not configurable here.

Mods

Mods add panels, status bars, commands and helpers around your chats. They use the same format as Claude Code mods, so mods installed there appear here too. Type /mods in a chat to open the switchboard.

Mods are programs. A mod you turn on can read and write files, run commands and see your conversations, with your permissions. Turn on only mods you trust.

New mods are saved in ~/.GrizzyCode/mods — not in Claude Code or any marketplace. Use Publish on a mod to add it to a marketplace folder you choose.

Plugins

A plugin bundles skills, connectors and slash commands. Install one from a folder or a .plugin / .zip file.
